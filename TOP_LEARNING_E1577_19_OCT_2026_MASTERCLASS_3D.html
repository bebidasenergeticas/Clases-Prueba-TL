    Distinción obligatoria

    Tres palabras que no son sinónimos

    Tool

    Capacidad que permite realizar una operación concreta: leer un PDF, buscar en la web, crear un archivo, enviar un mensaje.
    Instrumento de trabajo. Como la calculadora o el teléfono de la oficina.
    Tener la tool ≠ estar autorizado a usarla en cualquier situación.

    Skill

    Procedimiento o conjunto reutilizable de instrucciones que orienta al agente sobre cómo hacer una tarea.
    Manual de procedimiento. “Así hacemos el briefing en esta empresa.”
    Una skill no concede permisos por sí misma: solo orienta.

    MCP

    Protocolo para conectar clientes de IA con herramientas y recursos a través de servidores compatibles.
    Mecanismo estandarizado de conexión. Como un enchufe universal.
    MCP no reemplaza al modelo ni a la lógica de aprobación.
    Objetivo

    Fijar las tres definiciones con analogías laborales.

    Tiempo

      Arquitectura real

      Cuatro piezas, una conversación

      Telegram

      Gateway de Hermes
      Puente de mensajería · debe estar activo
      Perfil del agente
      Mano Derecha IA

      OpenRouter · archivos · skills
      ¿Qué es un bot?
      Una cuenta de Telegram controlada por software. Se crea con @BotFather y se identifica con un token secreto.
      ¿Qué es un gateway?
      El proceso que recibe mensajes de Telegram, se los entrega a tu agente y devuelve la respuesta.
      ¿Por qué debe estar activo?
      Si el gateway o el equipo se apagan, nadie está escuchando: el bot no responde.
      ¿Autorizar usuarios?
      Lista de IDs numéricos permitidos. Según la doc de Hermes, sin esa lista el gateway niega a todos por defecto.
      ¿Permitir o bloquear?
      Se puede limitar qué comandos usa cada usuario, y las acciones riesgosas piden aprobación (sí / no) en el chat.
      Objetivo

      Explicar sin tecnicismos qué es un bot, un gateway y por qué la autorización importa.

      Tiempo

      Una buena regla es SI … ENTONCES …

      SI

      SI
      la acción es irreversible (borrar, pagar) → aprobación + registro obligatorio.
      SI
      nadie responde en X horas → recordatorio o cancelación segura, nunca envío automático.

      Seguridad por capas

      Un prompt no garantiza seguridad

      Datos recuperadosno confiables
      Instrucciones autorizadastú + perfil
      Herramientas disponibleslo que existe
      Permisos efectivoslo que se permite
      Validación externaaprobación · registro
      Datos recuperados: documentos, correos, webs. Se leen, no se obedecen.
      Instrucciones autorizadas: solo las tuyas y las del perfil del agente.
      Herramientas disponibles: tener una tool no significa poder usarla siempre.
      Permisos efectivos: usuarios autorizados, comandos permitidos, accesos mínimos.
      Validación externa: aprobación humana y registro fuera del modelo.
