1.1 Qué estudiamos en la semana 12

Explicado en clase El profesor abrió la sesión con el tema «Asistentes de código para no programadores y delegación operativa con agentes» y con una pregunta guía: ¿cómo modificar software sin programar y automatizar flujos de trabajo en el mercado actual? La clase anterior había quedado pendiente probar OpenCode, así que esta sesión fue «guiada directo hacia OpenCode».

Los objetivos anunciados al inicio fueron cuatro:

  1. Conocer los asistentes de código (Cursor, GitHub Copilot) que ayudan a modificar código aunque no sepas programar.
  2. Practicar con un agente de programación —OpenCode— y conocer las alternativas profesionales Codex (OpenAI) y Claude Code (Anthropic).
  3. Aprender a identificar tareas de tu trabajo que puedes delegar hoy a agentes que ya existen.
  4. Ver un poco más de n8n, Microsoft Copilot Studio y voz con inteligencia artificial (OpenAI y xAI).

1.2 Por qué usar agentes de programación si «no soy programador»

Explicado en clase La idea central de la sesión: la habilidad clave ya no es escribir código, sino orquestar y supervisar agentes inteligentes. Un agente de código no solo «edita líneas»: puede planear, escribir, ejecutar, probar y corregir un proyecto completo a partir de instrucciones en lenguaje natural.

Lo que ganas

  • Crear herramientas a la medida (una calculadora, un CRM sencillo, una landing page).
  • Delegar tareas repetitivas o puntuales y dedicar tu tiempo a lo creativo.
  • Publicar en internet sin contratar desarrollo para proyectos pequeños y medianos.

Lo que sigue siendo tu responsabilidad

  • Saber qué pedir (conceptos básicos: repositorio, push, main, base de datos…).
  • Revisar y validar el resultado: el agente puede equivocarse.
  • Proteger datos, contraseñas y claves API.
Frase de la clase«Lo mismo que haría un CEO en una empresa: tal vez no conoce el área operativa a detalle, pero sí tiene que saber dónde está parado.» El profesor insistió en que no necesitamos escribir código, pero sí aprender algunos conceptos para dirigir bien al agente.

1.4 Competencias que tendrás al terminar

01
Delegar con criterio
Distinguir IA asistida, automatización por reglas y agentes autónomos, y elegir el nivel de supervisión.
02
Operar OpenCode
Instalar, elegir modelo, vincular carpeta, abrir sesiones y usar el navegador integrado.
03
Construir apps útiles
Crear una calculadora de automatización y validar sus fórmulas de ROI y payback.
04
Meta-prompting
Convertir una idea vaga en una especificación precisa con ayuda de otra IA.
05
Orquestar agentes
Hacer que OpenCode y Claude Code trabajen sobre el mismo proyecto sin pisarse.
06
Publicar en la web
Conectar GitHub CLI de forma segura y desplegar en GitHub Pages, verificando el resultado.

Conocimientos previos: ninguno de programación. Necesitas una computadora (Windows o macOS; OpenCode de escritorio no funciona en celular), conexión a internet, una cuenta de correo y, para meta-prompting, acceso a ChatGPT o Claude.
