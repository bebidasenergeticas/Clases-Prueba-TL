Práctica 4 · Meta-prompting con ChatGPT

Usar una IA para escribir el prompt que ejecutará otra IA. La técnica que más diferencia hizo en los resultados de la clase.

Realizado en clasePrompt original P07

9.1 ¿Qué es el meta-prompting?

Prompt inicial (vago)

Hazme una página bonita para mi negocio.

El agente debe adivinar: qué negocio, para quién, qué secciones, qué estilo, qué datos usar. Resultado: genérico.

Prompt mejorado (especificación)

Problema que resuelve · cliente objetivo · propuesta de valor · secciones · estilo visual · funciones · datos disponibles · restricciones («no inventes precios») · criterios de aceptación («botón de WhatsApp funcional, sin desbordes en móvil»).

Observación del profesor al finalAl usar el mismo modelo, las landing de dentistas «solo cambiaban colores»; la de una estudiante que hizo meta-prompting «parece de otra herramienta». Opinión del profesor «Mucho mejor siempre en ChatGPT» para la parte de meta-prompting.

9.2 Prompt original de meta-prompting

Mensajes siguientes del profesor (chat 01:41:18 y 01:41:27): «Para ChatGPT» · «Y al ultimo de como quieren la landing page». Es decir: después de PROMPT ORIGINAL: cada quien describe su landing page.

9.3 Flujo de uso paso a paso

  1. Abre ChatGPT (o Claude) en el navegador.
  2. Pega el meta-prompt completo.
  3. Debajo de PROMPT ORIGINAL: describe tu negocio.
  4. Explica el público objetivo.
  5. Define la propuesta de valor.
  6. Indica el estilo visual (colores, referencias, sensación).
  7. Enumera las funciones (WhatsApp, formulario, demo, planes…).
  8. Añade restricciones (no inventar precios ni testimonios).
  1. Envía.
  2. Lee el prompt optimizado: ¿conserva tu idea?, ¿añadió cosas que no pediste?
  3. Cópialo completo.
  4. Abre OpenCode, en tu carpeta, sesión nueva.
  5. Pega la versión optimizada.
  6. Pide que construya la aplicación.
  7. Revisa el resultado en navegador y móvil.
  8. Solicita correcciones agrupadas.
Paralelo en clasePara no perder tiempo, el profesor indicó: el prompt de DENTEA se ejecuta en OpenCode mientras el meta-prompt se trabaja en ChatGPT; luego se pega la respuesta de ChatGPT en OpenCode, y mientras ambos trabajan se continúa con la teoría.

9.5 Errores comunes

  • Demasiadas funciones sin contexto: el agente reparte esfuerzo y nada queda bien.
  • No decir qué problema resuelve la app.
  • No especificar a quién va dirigida.
  • No proporcionar datos (horarios, servicios): el agente inventa.
  • Confundir apariencia con funcionamiento: un botón bonito que no hace nada.
  • No validar el resultado en móvil y en los botones.
  • Iteraciones redundantes que gastan tokens.
  • Tecnologías incompatibles: el meta-prompt puede añadir frameworks, backend o pagos que tu entorno o GitHub Pages no soportan. Revisa y elimina lo que sobre.

9.6 Meta-prompt reutilizable (subagente)

Prompt mejorado El subagente creó un meta-prompt con campos editables —[NOMBRE_DEL_NEGOCIO], [CLIENTE_OBJETIVO], [PROBLEMA], [PRODUCTO_O_SERVICIO], [OBJETIVO_DE_LA_WEB], [ESTILO_VISUAL], [FUNCIONES], [DATOS_DISPONIBLES], [RESTRICCIONES]— para repetir el método con cualquier negocio después del curso. Está íntegro en el Anexo B2 (sección P07).

ConsejoGuarda tu prompt optimizado en un archivo PROMPT.md dentro de la carpeta del proyecto. Así cualquier agente (OpenCode, Claude Code, Codex) puede leerlo después como contexto.

Práctica 5 · Landing page personalizada

De DENTEA a tu propio proyecto: negocio, problema, propuesta de valor, meta-prompting, construcción y publicación.

10.1 La ruta

  1. Elige un negocio real o personal: tu emprendimiento, un proyecto, un servicio que quieras validar.
  2. Identifica el problema que resuelve para su cliente.
  3. Redacta la propuesta de valor en una frase: «Ayudo a [cliente] a [resultado] sin [dolor]».
  4. Meta-prompting (capítulo 9) con ChatGPT.
  5. Construcción en OpenCode en una carpeta propia.
  6. Revisión: textos, datos provisionales, botones, móvil.
  7. Publicación (capítulo 14) y enlace al muro de Top Learning, como pidió el profesor.
Incidencia real (≈ 2:27)Una estudiante contó que el agente la guiaba con preguntas («¿quieres ponerle esto?») pero no construía la página, y le pidió pagar un hosting; ella se negó y el agente sugirió publicar en Canva. Lección: el prompt debe decir explícitamente «construye el código ahora en esta carpeta; no publiques ni contrates nada». La publicación es un paso aparte (y gratuito con GitHub Pages).

10.2 Caso de estudio: Stilís, una aportación estudiantil

Realizado en clase Una estudiante construyó y publicó la landing de Stilís, una app de asistencia personal de estilo con el lema «Tu estilo. Listo.». Usó el meta-prompting («pedí que me hiciera el metaprompting y ya se lo pasé») y el modelo gratuito de OpenCode. El profesor la mostró en pantalla: «parece de otra herramienta», con animaciones y un selector para cambiar tipos de outfit. Faltaban fotos de productos.

Estructura de su prompt (chat 03:15:51)

  • Objetivo: presentación, demostración y conversión antes de solicitar acceso.
  • Rol: director creativo, UX/UI y frontend senior.
  • Marca: nombre con acento obligatorio, tono cercano, sin imponer estándares de belleza, rosa mexicano como acento, estética editorial + claridad tecnológica, sin inventar logotipo.
  • Ocho secciones: navegación, portada, cómo funciona (3 pasos), funcionalidades, demo interactiva marcada como ilustrativa, cinco planes, FAQ, cierre.
  • Datos honestos: planes sin precios inventados, configuración editable, «Detalles próximamente», no confirmar registros que no se guardaron.
  • Implementación: React + TypeScript si el entorno lo permite, textos centralizados, mobile first, accesibilidad, prefers-reduced-motion.
  • Criterios de aceptación verificables y orden de probar y corregir.
Autoría y permisoEl prompt de Stilís es trabajo de una estudiante, no del profesor. Como no consta autorización para redistribuirlo, esta guía no lo reproduce íntegro: se conserva en el registro interno de trazabilidad. Aquí se analiza su estructura; en el Anexo B2 hay una recreación didáctica claramente diferenciada.
PublicaciónSe desplegó en Firebase Hosting, no en GitHub Pages. El profesor lo aceptó: «lo pueden desplegar en cualquier otro lugar». El enlace se omite por privacidad. Estado actual no verificado

Qué demuestra el caso

Un buen meta-prompt cambia el resultado con el mismo modelo gratuito. Las claves fueron: identidad de marca precisa, una sección interactiva con propósito, honestidad sobre lo que aún no existe (precios, conexión real con IA) y criterios de aceptación. Es un modelo excelente para tu propio proyecto.
