Práctica 6 · Crear una cuenta en GitHub

Conceptos esenciales para principiantes absolutos y registro de la cuenta.

Realizado en clase

12.1 Primero, los conceptos

GitPrograma que guarda el historial de cambios de una carpeta, como «versiones» de un documento.
GitHubSitio web donde se guardan carpetas con Git (repositorios) en la nube y se colabora.
RepositorioEl proyecto + su historial. Puede estar en tu PC (local) y en GitHub (remoto).
GitHub PagesServicio de GitHub que publica gratis un sitio estático desde un repositorio.
Publicar (deploy)Poner la página en un servidor para que cualquiera la vea con un enlace.
CommitGuardar un punto del historial con un mensaje.
PushEnviar commits de tu PC a GitHub.
Branch / mainRama: línea de trabajo. main es la principal.

Público vs. privado

Público: cualquiera puede ver el código. Privado: solo tú y quien invites. Verificado Con una cuenta gratuita, GitHub Pages solo funciona en repositorios públicos; en privados requiere GitHub Pro, Team o Enterprise. Por eso nunca debe haber secretos en el código.

Por qué el profesor insistió

«El hecho de ya tener GitHub es importantísimo»: una vez conectado, cualquier práctica futura se publica con una frase, y Claude Code o Codex pueden «conectarse al repositorio» y seguir trabajando.

Confusión real de la claseUna estudiante creyó que su DENTEA «ya estaba desplegada» porque el agente lo dijo, pero solo estaba en local (en su carpeta). Desplegado significa que tiene un enlace público que abre en otro dispositivo.

12.2 Registro de la cuenta

Enlace compartido (chat 02:29:31): https://github.com/

  1. Entra al sitio oficial escribiendo github.com. Desconfía de enlaces en correos o anuncios.
  2. Crea la cuenta («Sign up»). Puedes registrarte con correo o, como sugirió el profesor, con tu cuenta de Google si se ofrece la opción.
  3. Elige un nombre de usuario. «No tiene que ser su nombre»; aparecerá en tus enlaces (usuario.github.io), así que elige algo profesional. Se puede cambiar después, pero cambia los enlaces.
  4. Confirma tu correo con el código que GitHub envía por correo (este sí llega por email; no lo confundas con el código de GitHub CLI del capítulo 13).
  5. Completa las verificaciones (rompecabezas antispam, preferencias). Activa la verificación en dos pasos (2FA) cuando GitHub lo solicite.
  6. Llega al panel principal (Dashboard).
  7. Reconoce tu perfil: clic en tu avatar → Your profile / Your repositories.
Guarda tus credencialesRecuerda el correo y la contraseña (el profesor lo pidió: los necesitarás al autenticar desde OpenCode). Usa un gestor de contraseñas. Nunca pegues tu contraseña, un código 2FA o un token en el chat de un agente.
¿Y si ya tengo otra plataforma?Una estudiante preguntó si podía desplegar en Firebase: «Sí… lo pueden desplegar en cualquier otro lugar». GitHub Pages es la opción guiada en clase porque es gratuita y se integra con los agentes.
