3.2 Fichas por herramienta

OpenCode Practicado

Qué es: agente de programación de código abierto; su código es público y auditable. Problema que resuelve: acceso a un agente completo sin pagar el software, con modelos gratuitos o el proveedor que elijas (más de 70 proveedores, según observó una estudiante). Clave: trabaja por carpetas y pide permiso antes de salir de ellas. Verificar: modelos gratuitos y planes en opencode.ai.

Claude Code Demostrado

Qué es: agente de Anthropic. En clase se abrió la app de escritorio, se creó un «nuevo entorno local» sobre la misma carpeta de OpenCode y se lanzaron subagentes. Para qué: cambios complejos, diseño, revisión. Requiere: suscripción o API. No se practicó por todos.

Codex Explicado

Equivalente de OpenAI a Claude Code. El profesor lo considera muy rápido para navegador. Las tareas en la nube requieren un repositorio de GitHub. No se demostró en esta sesión.

Cursor Explicado

Editor «arnés» de IA. El profesor no lo usó en clase porque «a la mitad se acaba el uso gratis». Útil para quien quiere ver y editar archivos con apoyo visual.

GitHub Copilot Explicado

Sirve sobre todo cuando ya tienes código y quieres corregir o añadir pequeños cambios. Opinión «No es para no programadores»; pero puede venir en evaluaciones.

GitHub Practicado

Plataforma donde se guardan repositorios de código y desde donde se publicó con GitHub Pages. Ver capítulos 12–14.

n8n · Make · Zapier Explicado

Plataformas de automatización por flujos (nivel 2). En el curso se profundiza en n8n. En clase se omitió la diapositiva de n8n por haberse visto antes. La calculadora recomendaba entre estas herramientas.

Microsoft Copilot Studio Explicado

Plataforma low-code para agentes conversacionales con RAG (responder con tus archivos), acciones mediante conectores y Power Automate, y publicación multicanal (web, Teams). Opinión Conviene si trabajas en el ecosistema Microsoft.

xAI · agentes de voz Demostrado

Consola para crear agentes que hablan en tiempo real, con interrupciones y baja latencia. Se comparó con OpenAI Realtime. Ver capítulo 11.

Google Flow Demostrado

Herramienta de Google para generar video e imágenes con IA. El profesor la usa como «prueba de fuego» del navegador de cualquier agente. Verificar disponibilidad y planes de tu cuenta; no fue posible consultar su sitio desde el entorno de elaboración de esta guía.

3.3 ¿Cuál elegir?

Explicado en clase «No hay un ganador absoluto. Elige por presupuesto, privacidad y proyecto.» Una estrategia que el profesor usa y recomendó:

  1. Base con OpenCode y un modelo gratuito o barato: estructura, primeros archivos, comandos repetitivos.
  2. Cambios pesados con un agente más potente (Claude Code o Codex) cuando tengas acceso: diseño fino, lógica compleja, revisión de seguridad.
  3. Un solo lugar común: la misma carpeta o el mismo repositorio, para que ambos lean el mismo proyecto (capítulo 7).
Cuidado con las API de pagoOpenCode permite conectar proveedores con tu propia clave API. El profesor relató haber gastado ≈ 25 % de un plan anual de API en un solo día por un error, y advirtió que elegir por accidente un modelo caro puede agotar 100 USD en un par de aplicaciones de prueba. Con una suscripción el peor caso es agotar el límite semanal; con una API, el gasto puede seguir hasta donde llegue tu saldo. Si conectas una API: fija límites de gasto, usa claves con presupuesto y no compartas la clave.
