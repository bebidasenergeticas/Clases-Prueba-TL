19.1 Examen de autoevaluación

1. ¿Qué diferencia a un agente de programación de un asistente como Copilot?
R: el agente recibe una tarea y lee, edita, ejecuta y verifica en varios pasos; el asistente apoya al programador línea a línea.

2. ¿Por qué «gratis no es ilimitado» en OpenCode?
R: el software es gratuito, pero los modelos free tienen límites y son temporales; conectar una API cobra por uso.

3. Un proceso de 2 h, 1 vez/semana, 2 personas, 70 % automatizable, 48 semanas: ¿horas recuperables al año?
R: 2×1×2×48×0.7 = 134.4 h.

4. ¿Por qué el payback debe calcularse con el beneficio neto?
R: porque los costos recurrentes reducen el flujo real; con el bruto el plazo parece más corto.

5. ¿Qué significa «horas liberadas ≠ dinero ahorrado»?
R: solo hay ahorro monetario si se reduce un costo o se reasigna el tiempo a trabajo productivo medible.

6. ¿Cómo se «comunican» OpenCode y Claude Code sobre una carpeta?
R: indirectamente, leyendo los archivos que el otro deja; no hay protocolo automático.

7. ¿Qué hace el meta-prompting?
R: una IA transforma tu intención en un prompt optimizado que ejecutará otra herramienta.

8. ¿Dónde aparece el código de GitHub CLI?
R: en la terminal/OpenCode; no llega por correo. Se introduce en github.com/login/device.

9. Ves una ventana de permisos con un editor desconocido. ¿Qué haces?
R: rechazar, averiguar qué programa era y reinstalar desde la fuente oficial.

10. ¿Por qué un repositorio privado no publicó en Pages con cuenta gratuita?
R: GitHub Free solo permite Pages en repositorios públicos.

11. ¿Qué comando confirma qué cuenta está conectada?
R: gh api user --jq .login (o gh auth status).

12. El agente propone Netlify porque falló GitHub. ¿Qué respondes?
R: que no cambie de plataforma y diagnostique el paso fallido.

13. ¿Por qué no confiar en un precio dicho por un agente de voz en una demo?
R: puede alucinar o leer datos viejos; la información oficial debe venir de fuentes aprobadas.

14. ¿Cuándo está realmente publicado un sitio?
R: cuando su enlace abre en otro dispositivo con el contenido correcto.

15. ¿Qué riesgo tiene que dos agentes editen el mismo archivo a la vez y cómo se evita?
R: sobrescritura o conflicto; se asignan archivos, ramas o turnos y se integra de forma controlada.
