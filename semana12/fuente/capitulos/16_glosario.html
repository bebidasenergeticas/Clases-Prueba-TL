Capítulo 16

Glosario profesional para principiantes

La terminología que el profesor prometió facilitar. Organizado por categorías. Formato: definición · ejemplo y uso en clase · error frecuente.

16.1 Inteligencia artificial y agentes

IA generativa
IA que crea contenido nuevo (texto, imágenes, código, voz). Ej.: ChatGPT redactando, Flow generando video. Error: creer que «sabe» todo; predice a partir de patrones.
LLMLarge Language Model
Modelo de lenguaje grande entrenado con enormes cantidades de texto. GLM, DeepSeek, Sonnet, GPT. Error: confundir el modelo con la app que lo usa.
Modelo
El «cerebro» concreto que elige OpenCode para pensar. En clase: GLM 5.3 Flash (gratuito). Error: elegir uno caro por accidente con una API conectada.
Agente
Sistema que persigue un objetivo usando herramientas en varios pasos. OpenCode creando y publicando la calculadora. Error: darle objetivos ambiguos («gana dinero»).
Subagente
Agente auxiliar lanzado por otro para una tarea acotada. Catálogo de 327 procesos. Error: dejar que dos editen el mismo archivo.
Orquestador
Quien coordina agentes y une resultados. Claude Code esperando a sus subagentes; tú como director. Error: no revisar lo que integran.
Prompt
La instrucción que das al modelo. P01–P12. Error: pedir mucho sin contexto ni criterios.
Meta-prompting
Usar una IA para mejorar el prompt que ejecutará otra. ChatGPT → OpenCode, cap. 9. Error: pegar el resultado sin leerlo.
Contexto
Información que el modelo tiene disponible para responder. «Contexto completo de carpetas». Error: carpeta vacía = poco contexto.
Tokens
Unidades de texto con que se mide y cobra el uso. Cada mensaje relee la conversación. Error: charlar sin rumbo en conversaciones largas.
Ventana de contexto
Máximo de tokens que el modelo puede considerar a la vez. Al llenarse, la app resume («compacta») la conversación. Error: asumir que recuerda todo para siempre.
Skills
Habilidades configurables (instrucciones y recursos) que un agente carga para tareas especializadas. Mencionadas para Claude Code y OpenCode. Error: instalar skills de origen dudoso.
MCPModel Context Protocol
Estándar para conectar agentes con herramientas y servicios externos. El MCP de n8n para crear flujos. Error: dar permisos de escritura sin necesidad.
Human-in-the-loop
Punto donde una persona aprueba antes de actuar. Revisar borradores; aprobar compras y envíos masivos. Error: dejar autónomo lo que afecta a clientes o dinero.
RAG
Responder recuperando información de tus documentos. Copilot Studio (la transcripción dice «RAC»). Error: documentos desactualizados = respuestas erróneas.
Agente de voz
Agente que conversa por audio en tiempo real. Demo de xAI. Error: confiar en precios o teléfonos que «dice».
Latencia
Tiempo de respuesta. Muy baja en la demo de voz. Error: ignorarla en llamadas reales.

16.2 Desarrollo y entorno

Terminal / PowerShell
Ventana para dar órdenes escritas a la computadora; PowerShell es la de Windows. Ventana de autorización de GitHub CLI. Error: asustarse o, al revés, ejecutar comandos sin entenderlos.
CLI
Programa que se usa desde la terminal. gh. Error: buscarlo como app con ventanas.
IDE
Editor de código con herramientas (VS Code, JetBrains). Cursor está basado en VS Code. Error: creer que es obligatorio para usar agentes.
Open source
Software cuyo código es público y auditable. OpenCode. Error: pensar que implica modelos gratis.
Frontend / Backend
Frontend: lo que ves en el navegador. Backend: servidor, lógica y datos ocultos. GitHub Pages solo sirve frontend. Error: poner claves de backend en el frontend.
Base de datos
Lugar organizado para guardar datos. CRM del ejemplo de la dulcería. Error: guardar datos personales sin protección.
HTML · CSS · JavaScript
Estructura, estilo y comportamiento de una página. index.html de la calculadora. Error: editar a mano sin respaldo.
React · TypeScript
React: librería para interfaces por componentes. TypeScript: JavaScript con tipos. Framer Motion (DENTEA) requiere React; Stilís pedía React+TS. Error: olvidar que requieren compilación (build).
Dependencia
Paquete externo que el proyecto necesita (npm install). Framer Motion. Error: subir la carpeta node_modules.
API · API key
Interfaz para que programas se comuniquen; la key es la «llave» que te identifica y cobra. Advertencia de costos del profesor. Error: publicar la key en el código o el chat.
OAuth
Forma de autorizar a una app sin darle tu contraseña. Código de dispositivo de GitHub CLI. Error: aceptar permisos sin leerlos.
Permisos (ask/allow/deny)
Reglas de qué puede hacer el agente sin preguntar. OpenCode pide permiso antes de comandos. Error: «permitir todo siempre».
Webhook
URL que recibe datos automáticamente cuando ocurre un evento. Agente de voz → n8n. Error: dejarla pública sin validación.
n8n
Plataforma de automatización por flujos, autohospedable. Recomendada por la calculadora. Error: usarla para tareas que requieren juicio sin IA ni revisión.

16.3 Git, GitHub y publicación

Repositorio
Proyecto con historial. El de la calculadora del profesor. Error: un repo con varios proyectos mezclados.
Git · GitHub · GitHub CLI
Historial local · plataforma en la nube · herramienta de terminal de GitHub. Instalados con P09/P11. Error: confundir GitHub (sitio) con Git (programa).
Commit · Push · Pull
Guardar un punto · subirlo · traer cambios. «Cuando me pidió subir el commit era para hacer el cambio en GitHub». Error: push forzado que borra trabajo ajeno.
Branch · Main · Merge
Rama · rama principal · unir ramas. Ramas separadas para dos agentes. Error: trabajar todos en main a la vez.
Pull request
Propuesta de cambios para revisar antes de unirlos. Claude Code puede crear PR. Error: aprobar sin revisar.
Deploy · Hosting
Publicar · servicio que aloja el sitio. GitHub Pages, Firebase. Error: creer que «local» es «publicado».
Dominio · HTTPS
Dirección web · conexión cifrada (candado). Dominio propio ≈ compra anual. Error: introducir datos en sitios sin HTTPS.
GitHub Pages · Actions
Alojamiento estático gratuito · automatizaciones de GitHub (p. ej. compilar y publicar). Práctica 8. Error: repo privado en cuenta gratuita.

16.4 Negocio y seguridad

Dashboard · KPI
Panel visual · indicador clave. Gráficas de la calculadora. Error: KPIs bonitos sin datos reales.
ROI · Payback
Rentabilidad sobre la inversión · tiempo para recuperarla. Cap. 6.4. Error: usar ahorro bruto como neto.
Seguridad de credenciales
Proteger contraseñas, tokens, keys y códigos. Nunca en el chat. Error: compartir capturas con códigos visibles.
