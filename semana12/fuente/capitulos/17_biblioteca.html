17.1 Cómo se elaboró

Los prompts se auditaron con un subagente especializado (PROMPT_AUDITOR_E1601) que leyó completos el chat y la transcripción. Modelo solicitado: Claude Sonnet 5.5 con esfuerzo alto. El subagente se identificó como Sonnet 5.5; el nivel de esfuerzo se solicitó como alto en la configuración de la tarea, aunque el propio subagente no pudo confirmarlo desde dentro. Verificó comandos en documentación primaria (cli.github.com, docs.github.com, código fuente de GitHub CLI) el 22-nov-2026 y comprobó por programa que los 14 bloques de texto literal coinciden exactamente con el chat.
